# MERN Blog Application

A full-stack blog application built with the **MERN stack (MongoDB, Express.js, React, Node.js)**. Users can create, edit, delete, and view blog posts in a clean, responsive interface.

---

## 🚀 Features

- 📝 User authentication (Login/Register)
- ✍️ Create, read, update, and delete blog posts
- 📸 Upload cover images for posts
- 🔐 JWT-based authentication
- 📱 Responsive design (mobile/tablet/desktop)
- 🗃️ MongoDB for data persistence
- 🧠 React state management and routing

---

## 🛠️ Technologies Used

- **Frontend**: React, Axios, React Router
- **Backend**: Node.js, Express.js
- **Database**: MongoDB with Mongoose
- **Authentication**: JSON Web Tokens (JWT)
- **Styling**: CSS/SCSS (or Tailwind, if added)
- **File Upload**: Multer (optional based on project config)
